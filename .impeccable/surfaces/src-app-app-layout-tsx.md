# Surface: JAC Arango app shell (all authenticated screens + login)

Mode: Operate. Audience: JAC board, encuestadores, fontanero in the field on low-end phones in sunlight; older adults, low digital literacy. Job: find a house, register a visit, check water status, never lose a record.

## Direction contract
FORM: Fachadas de Concepción (user choice over roll; seed:fb5bdec6d65abdf6, kind: pick)
THESIS: The app is the vereda's own house front: a whitewashed working surface with painted woodwork carrying meaning. Refuses the grey SaaS dashboard with one blue accent.
OWN-WORLD: Whitewash ground (cool white, never cream), deep balcony green shell (top bar / rail), painted-door accents: water blue = acueducto, tile red = alert/destructive, ochre = pending. Ink near-black. System sans for speed, tabular numerals. Hairline 1px rules, 10px radius, generous 48px targets.
SIGNATURE: the zócalo, a painted baseboard band along the bottom edge of each house card/row and key panels; its colour states the record's status (blue = uses acueducto, ochre = pending sync / missing data, red = no data authorization, plain wall = neither).
FIRST VIEWPORT: green balcony bar with name + sync state; greeting; three tally tiles (houses vs goal with progress, people, water users) each with its zócalo; primary action "Registrar visita" full width on phone.
RAISES: from design-annual plate: one type family, strict hairline grid discipline. From datamatics: tabular figures for every count, code and coordinate.
RISK: Colors of the Concepción flag are not yet confirmed; palette lives in tokens to swap.
